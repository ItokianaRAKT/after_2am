# After 2 AM

> A short interactive story played entirely in the command line.

## About

**After 2 AM** is a small narrative game written in Python and built around player choices.

You play as an ordinary high school student whose identity is never specified. One night, at exactly **02:13**, strange events begin to unfold.

The game combines interactive storytelling, exploration, puzzles, and horror atmosphere.

## Features

- Interactive command-line story
- Multiple choices affecting the progression
- Three-day story progression
- USB drive and hidden file puzzle
- Password system
- Fictional `SCENE` application
- Time-based narrative centered around 02:13

## Technologie

- Python 3

No external dependencies are required.
